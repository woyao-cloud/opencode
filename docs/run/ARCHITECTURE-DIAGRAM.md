## 二、数据流图（一次用户输入到 AI 响应）

```text
用户输入: "帮我修复 src/auth 下的类型错误"
    │
    │  按下 Enter
    ▼
┌──────────────────────────────────────────────────────────────────────────┐
│ TUI Prompt 组件 (主线程)                                                   │
│                                                                           │
│ submitInner()                                                             │
│   ├─ 验证 (disabled? empty? agent?)                                       │
│   ├─ 创建 Session (无 sessionID 时)                                       │
│   │   sdk.client.session.create({agent, model})                          │
│   │   → RPC → Worker → SQLite → sessionID                                │
│   └─ 发送消息                                                             │
│       sdk.client.session.prompt({                                         │
│         sessionID, agent, model,                                          │
│         parts: [                                                          │
│           {type:"text", text:"帮我修复..."},   ← 用户文本                  │
│           {type:"text", text:editorContext},   ← 编辑器选中               │
│           {type:"file", url, filename},        ← 文件引用                  │
│         ]                                                                 │
│       })                                                                  │
└────────────────────────────────────┬─────────────────────────────────────┘
                                     │
                                     │ RPC: client.call("fetch", {...})
                                     ▼
┌──────────────────────────────────────────────────────────────────────────┐
│ Worker 线程                                                                │
│                                                                           │
│ HTTP POST /session/{id}/message                                           │
│   → server/routes/.../session.ts (路由)                                   │
│     → session/prompt.ts::prompt()  ← 进入 Effect 世界                     │
│                                                                           │
│       ┌─ createUserMessage() (Effect.gen) ──────────────────────────┐     │
│       │ · Agent 查找 → agent/agent.ts                               │     │
│       │ · Model 确定 → provider/provider.ts                         │     │
│       │ · Part 解析 → resolvePart() (Effect.forEach 并发)           │     │
│       │ · 消息保存 → session/session.ts (SQLite)                    │     │
│       │ · 事件发布 → bus/index.ts                                   │     │
│       └─────────────────────────────────────────────────────────────┘     │
│                                     │                                      │
│       ┌─ runLoop() (Effect.gen, while true) ───────────────────────┐     │
│       │                                                             │     │
│       │  STEP N:                                                    │     │
│       │  ① 加载消息 → filterCompactedEffect()                      │     │
│       │  ② 溢出检测 → compaction.isOverflow()                      │     │
│       │  ③ System Prompt 组装                                       │     │
│       │     Effect.all([environment, instructions, skills])         │     │
│       │  ④ 消息转换 → toModelMessagesEffect()                      │     │
│       │  ⑤ 工具注册 → resolveTools()                               │     │
│       │     · tool/registry.ts 内置工具                             │     │
│       │     · mcp/index.ts MCP 工具                                 │     │
│       │  ⑥ 调用 LLM → processor.process()                          │     │
│       │     → provider/transform.ts::message()                      │     │
│       │     → session/llm.ts::stream()                              │     │
│       │     → AI SDK → SSE 流 → 协议解析 → LLMEvent                │     │
│       │                                                             │     │
│       │  ⑦ 处理结果:                                                │     │
│       │     · text-delta → TextPart → 发布事件 → TUI 实时渲染       │     │
│       │     · tool-call → 工具执行 (见下方)                         │     │
│       │     · finish="stop" → break                                 │     │
│       │     · finish="tool_calls" → 执行工具 → continue            │     │
│       │                                                             │     │
│       │  ⑧ [如有 tool_calls] 工具调度:                              │     │
│       │     → permission/index.ts::ask()  权限检查                  │     │
│       │     → tool-runtime.ts::decodeAndExecute()  参数解码         │     │
│       │     → tool/*.ts::execute()  执行工具                        │     │
│       │     → tool/truncate.ts::output()  输出截断                  │     │
│       │     → 结果注入消息历史 → 回到 ①                             │     │
│       │                                                             │     │
│       │  循环退出:                                                   │     │
│       │  → compaction.prune() 后台清理                              │     │
│       │  → lastAssistant() 返回最终消息                             │     │
│       │  → 发布 session.status: idle                                │     │
│       └─────────────────────────────────────────────────────────────┘     │
└──────────────────────────────────────────────────────────────────────────┘
                                     │
                                     │ 事件回流: Bus → GlobalBus → RPC → 主线程
                                     ▼
┌──────────────────────────────────────────────────────────────────────────┐
│ TUI 事件消费 (主线程)                                                       │
│                                                                           │
│ EventSource 接收 Worker 推送的全局事件                                      │
│                                                                           │
│  message.part.updated:                                                    │
│   ├─ TextPart (time.end) → 消息时间线追加文本 (AI 逐字输出!)               │
│   ├─ ReasoningPart → 斜体灰色 "Thinking: ..."                             │
│   ├─ ToolPart (completed) → 图标+标题+耗时 内联展示                        │
│   └─ ToolPart (error) → ✗ 错误展示                                        │
│                                                                           │
│  session.status:                                                          │
│   ├─ type="busy" → Footer 显示 "处理中..."                                │
│   └─ type="idle" → Footer 显示 "就绪", 退出事件循环                        │
│                                                                           │
│  permission.asked:                                                        │
│   └─ 展示权限对话框 → 用户选择 → permission.reply()                        │
└──────────────────────────────────────────────────────────────────────────┘
```
