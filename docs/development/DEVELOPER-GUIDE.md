# opencode 开发者使用文档 · 总览

## 项目简介

opencode 是一个 AI 编程助手框架。它提供了一套完整的基础设施——从 LLM 通信到工具执行、从会话管理到多 Agent 协作——让开发者可以构建和定制 AI 编程助手。项目采用 monorepo 架构，包含 14 个包，覆盖 CLI 终端、Web 应用、桌面应用、SDK 客户端等多个交付形态。

## 技术栈

| 技术 | 用途 |
|------|------|
| **TypeScript** | 全项目类型安全 |
| **Bun** | JavaScript/TypeScript 运行时、包管理器、构建工具 |
| **Effect-TS** | 效应系统：类型安全错误处理、依赖注入、结构化并发、Schema 验证 |
| **SolidJS** | Web 应用端 UI 框架（细粒度响应式） |
| **React/Ink** | TUI 终端界面渲染 |
| **SQLite** | 本地数据持久化（会话、配置、事件） |
| **Ripgrep** | 代码搜索后端 |

## 快速启动

```bash
# 1. 克隆仓库
git clone <repo-url>
cd opencode

# 2. 安装依赖（Bun 自动处理 monorepo workspaces）
bun install

# 3. 类型检查
bun typecheck

# 4. 构建核心包
cd packages/opencode
bun run build

# 5. 运行 CLI
bun opencode run "hello"

# 6. 运行测试
bun test
```
