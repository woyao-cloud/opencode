关键发现

在实现过程中，发现 Effect 4.0.0-beta.65 与预期 API 有较多差异，所有 demo 代码均经过实际运行验证：

- Context.Tag → Context.Service 类模式
- Effect.catchAll → Effect.catch
- Schema.Lazy → Schema.suspend
- Effect.fork → Effect.forkScoped / Effect.forkDetach
- Layer.orElse → Layer.catchTag
- 以及 50+ 其他 API 差异，均在代码中修正并验证
